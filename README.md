# 电商带货视频拆解智能体

输入一个爆款带货视频，自动完成「逐字稿提取 → 钩子/结构拆解 → 可复制模板 → 对标方法论沉淀」，像顶级策划一样拆解并复用爆款套路。

## 项目背景

- **目标赛道**：电商带货（好物推荐、带货脚本）
- **核心产出**：文案逐字稿、钩子/结构拆解、可复制脚本模板、对标方法论
- **设计理念**：短视频拆解的核心壁垒不在工具，而在「拆解框架」。主流大模型已内置海量文案/营销方法论，只需用一套清晰的框架把它引导出来，无需海量数据蒸馏。

## 目录结构

```
.
├── README.md           # 项目说明（本文件）
├── 拆解框架.md          # 电商带货视频 · 顶级策划拆解框架（核心）
└── 案例库/             # 拆解案例沉淀（每拆一个，沉淀一个）
```

## 拆解框架速览

按「用户从刷到到下单的心理旅程」组织，五段转化闭环：

1. **停留** — 黄金 3 秒钩子
2. **共情** — 戳中需求
3. **说服** — 卖点与信任
4. **冲动** — 价格锚点与稀缺
5. **行动** — 成交指令

每个视频拆解输出九大模块（逐字稿、钩子拆解、结构骨架、卖点信任、情绪曲线、价格锚点、用户画像、可复制模板、方法论沉淀），详见 [`拆解框架.md`](./拆解框架.md)。

## 使用方法

1. 拿到一个爆款带货视频，提取文案（手动记录或语音转文字）。
2. 按 `拆解框架.md` 的九大模块逐项拆解。
3. 把拆解结果存入 `案例库/`，并提炼「可复制模板」和「方法论」标签。
4. 后续拆解同类视频时，检索历史案例作参考，效果滚雪球式提升。
